# KAIROSLOGIC DECISIONS

Última actualización: 2026-09-12

Propósito:

Mantener un registro de decisiones operativas, provisionales o pendientes
de institucionalización.

Este documento NO sustituye a los ADR.

Este documento NO sustituye al SSOT.

Una decisión incluida aquí no implica que sea conocimiento institucional.

Cuando una decisión quede formalizada mediante ADR o SSOT deberá
actualizarse su estado.

====================================================================
D-001
SEPARACIÓN ENTRE SSOT Y MEMORIA TEMPORAL
====================================================================

ESTADO:
APROBADA

DESCRIPCIÓN:

La memoria temporal y el conocimiento institucional deben mantenerse
separados.

SSOT:
Conocimiento permanente.

Memoria temporal:
Estado operativo vivo.

MOTIVACIÓN:

Evitar contaminación del conocimiento institucional.

SIGUIENTE PASO:

Mantener ambas capas desacopladas.

====================================================================
D-002
SNAPSHOT COMO MEMORIA TEMPORAL INICIAL
====================================================================

ESTADO:
APROBADA

DESCRIPCIÓN:

Utilizar inicialmente un único snapshot accesible por GitHub como
mecanismo común de continuidad entre IAs.

MOTIVACIÓN:

Simplicidad.
Acceso móvil.
Bajo coste.
Alta compatibilidad.

SIGUIENTE PASO:

Evaluar periódicamente si sigue siendo suficiente.

D-007
TELEMETRÍA DETERMINÍSTICA
====================================================================

ESTADO:
APROBADA

DESCRIPCIÓN:

Las métricas financieras deben calcularse por código determinístico.

MÉTRICAS AFECTADAS:

- Profit Factor
- Win Rate
- Sharpe
- Drawdown
- Curvas

MOTIVACIÓN:

Evitar dependencia de modelos IA para cálculos críticos.
