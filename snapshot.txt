# KAIROSLOGIC SNAPSHOT

Última actualización: 2026-09-12

Estado global:
Desarrollo activo.

Propósito:
Punto de entrada rápido para cualquier IA.
Este fichero NO es el SSOT.
Este fichero NO contiene conocimiento institucional completo.
Este fichero únicamente indica el estado operativo actual y dónde consultar cada línea de trabajo.

---

# REGLA DE USO

Secuencia obligatoria:

1. Leer snapshot.txt
2. Identificar el subproyecto relevante
3. Consultar el fichero temático correspondiente
4. Consultar SSOT y ADR únicamente si son necesarios
5. Diferenciar siempre entre:
   - Hecho verificado
   - Hipótesis
   - Decisión aprobada

# REGLAS FUNDAMENTALES

1. No modificar SSOT sin decisión humana.

2. No modificar ADR masivamente sin evidencia.

3. No asumir que algo existe porque esté documentado.

4. Verificar físicamente siempre que sea posible.

5. Evidencia antes que afirmaciones.

6. Mantener separadas:

Institución
Laboratorio
Evidencia
Memoria temporal
